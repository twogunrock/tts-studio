Voice

What a blend is

Kokoro comes with a few dozen built-in voices. A blend mixes two or more of them, the way you'd mix paint: half Heart and half Sarah gives a new voice somewhere between the two.

Why you'd blend

  • To sound like you, not like the stock voice everyone else downloads.
  • To soften a quirk. If one voice is a little too bright or breathy, mix in a steadier one.

How to do it

Start with one voice and listen. Then add a second and drag its slider. The bar shows how much of each voice is in the mix. Only the proportions matter: two voices at the same setting are always a 50/50 mix.

Tips

  • Two or three voices is plenty.
  • Stick to one accent. Mixing American and British voices tends to sound uncertain.

What it does

Give Chatterbox a short recording of someone speaking and it reads your script in a voice like theirs, picking up their tone and delivery.

Recording a good sample

  • About 10 seconds of one person talking naturally.
  • A quiet room: no music, no background voices.
  • Save it as a .wav file in the voices folder shown below, then reload this page.

Pronunciations

Words the voice gets wrong, and how they should sound. Both engines use this list.

What happens

Before anything is spoken, every place a word appears exactly as you typed it here is swapped for how it should sound. Capitals matter: "SQL" won't change "sql".

Writing how it sounds

  • Spell it the way you'd say it: SQL as "sequel", GUI as "gooey".
  • For letters said one at a time, separate them: AWS as "A W S", or "ay double-you ess" if the voice runs them together.
  • Use Hear it to try a spelling before you use it in a script.

Where it's kept

In overrides.json next to the studio, saved as you type. It's used whenever the pronunciation option under More controls is on, which it is by default.

Chatterbox is an optional add-on

Kokoro is enough for most people. If you've tried it and can't get the delivery you need, Chatterbox is more expressive, and it can copy a voice from a short recording.

What it costs

  • About 9 GB of disk space: a 6 GB install, plus a 3 GB download the first time you use it. Kokoro needs under 0.5 GB.
  • An NVIDIA graphics card, to be practical. Without one it still works, but about 20 times slower than real time: a one-minute script takes around 20 minutes.
  • About 4 GB of memory while it's in use (graphics memory with a card, regular memory without).
  • A separate Python setup that you install yourself, following Chatterbox's own instructions.

Adding it

  1. Install Chatterbox by following its instructions on GitHub. Install it into its own Python environment, not the one running this studio.

    In that same environment, also run pip install "setuptools<81". Without it, Chatterbox's AI watermark doesn't load and every clip comes out unmarked.

  2. Show the studio where you installed it. Paste the folder, or browse to it.

One line, one piece

Every line is spoken separately with a pause after it. That means you can fix one line and re-create only that line, without touching the rest.

Punctuation steers the delivery

  • A comma is a short breath. A colon builds a little anticipation.
  • A question mark sounds like a question. In Chatterbox, an exclamation mark lifts the energy.
  • A short line on its own reads as a heading and gets a longer pause.
  • Capital letters don't add emphasis. Rewording does.

A word comes out wrong?

Add it to Pronunciations once, and every script gets the fix. Select the word in the script first and the studio fills it in for you.

      Welcome to TTS Studio

      TTS Studio turns a written script into spoken audio, entirely on this computer. Nothing you type leaves your machine.

      Which engine?

      • Kokoro is built in. It's fast, small, runs on any computer, and is enough for most people. Start here.
      • Chatterbox is an optional add-on you install yourself. It's more expressive and can copy a voice from a short recording, but it's large and needs a good graphics card to be practical.

      Your first recording, in four steps

      1. Pick a voice in Voice settings, on the left (on a phone, tap Change). The default blend is a good place to start.
      2. Paste your script, one sentence or idea per line.
      3. Create audio in the bar at the bottom, and listen. The line being spoken lights up in your script.
      4. Happy with it? Name it and Save this take.

      Making it sound better

      • Too fast or too slow? Move Speaking speed.
      • Lines feel rushed together? Open More controls and lengthen the pauses.
      • One line sounds wrong? Reword it, select it, and use Create audio for selected lines.
      • Like the voice? Remember these settings and the studio opens that way next time.

      Where your files go

      Saved takes go in the exports folder next to the studio. Each take has the audio, the settings, your script and the text that was spoken.

      Using the audio

      Kokoro (Apache 2.0) and Chatterbox (MIT) both allow commercial use. Chatterbox audio carries an inaudible watermark marking it as AI-generated. Only copy voices you have permission to use.
